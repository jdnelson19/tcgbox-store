# TCG Box Store

TCG box store storefront built with React, TypeScript, and Vite.

## Project Structure

- `apps/storefront`: React + Vite storefront

## Run Locally

```bash
npm install
npm run dev
```

- Storefront: `http://localhost:5173`

## Build

```bash
npm run build
```

## Deployment

GitHub Pages deployment configuration is in `.github/workflows/deploy-pages.yml`.
